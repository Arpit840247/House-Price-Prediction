# House Price Prediction System
**IBM SkillsBuild Data Analytics with AI Internship 2026**

## Project Description
An end-to-end Machine Learning web application designed to predict real estate property prices using Linear Regression. The system features a Flask REST API backend and an intuitive Streamlit interactive frontend interface.

## Dataset Link
- **Dataset Source:** [Kaggle House Price Regression Dataset](https://www.kaggle.com/datasets)
- **Local Dataset:** `house_price.csv`

## Technologies Used
- **Language:** Python 3.x
- **Data Science:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
- **Backend:** Flask
- **Frontend:** Streamlit
